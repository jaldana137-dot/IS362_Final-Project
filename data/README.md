# data/

Drop the input CSVs here:

- `tracks.csv` and `artists.csv` -- from the Kaggle dataset
  [yamaerenay/spotify-dataset-19212020-160k-tracks](https://www.kaggle.com/datasets/yamaerenay/spotify-dataset-19212020-160k-tracks).
- `billboard_year_end.csv` -- generated by running `python ../02_scrape_billboard.py`.

These CSVs aren't checked into git because (a) they're huge and (b) the
licensing is iffy. Download/regenerate them yourself.
